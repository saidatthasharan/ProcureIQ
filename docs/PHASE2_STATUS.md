## Not run / not proven
- **No live Gemini call has been made.** No API key was available. Extraction accuracy, analyst tool choice and copilot drafting quality are UNMEASURED. `npm run eval:live` (needs GEMINI_API_KEY) compares extraction with the generator's expected values and prints exact counts.
- Stub-model tests prove wiring, validation and safety behaviour only.
- Default model name `gemini-3.8-flash` came from Google's models page; override with GEMINI_MODEL.

## Still simulated or sample data
- Questionnaire answers are sample inputs shipped with the project (not read from vendor files). They load as not buyer-verified and are labelled as such. They contain a known inconsistency (EcoWrap "Partial" status with all 12 answered).
- Sample vendor files are synthetic, generated by scripts/generate-fixtures.ts. The "angled handwritten photo" is a synthetic image.
- Email is not sent (clarification requests and addenda are recorded only). No ERP connection exists.
- RFx line items, supplier list, baseline prices and project metadata are sample project data.

## Not production-ready
- No user login, no per-user quota, no persistent database or audit log (the audit trail lives in browser memory for the session). In-memory rate limiter only.
- Analyst/copilot receive project state from the browser; the server does not hold a source of truth.
- Settings sliders (OCR threshold, GST, block-historical) are display only; the extraction pipeline uses a fixed 85% confidence threshold.
- Conditional-discount minimum award value is not checked against the award total. Lines with no usable price are costed at baseline in scenario totals (disclosed by the analyst).
